# Voice references

The WAV files in this directory are local test inputs for Chatterbox voice conditioning. They are not Sinema source code and are not covered by the repository MIT license.

The current profiles point to Chatterbox demo samples, including recordings labelled after recognizable fictional characters. Treat them as non-redistributable test material unless you have independently verified the recording, voice-reference, publicity, and commercial-use rights.

Before publishing this repository or a rendered demo, remove these WAV files and replace them with recordings you own or are explicitly licensed to redistribute. The source URLs and profile labels are kept in `voice-profiles.json` for review only.
