## Proposed beginner story

The problem: “I built a small app, but now I need somewhere to run it, somewhere to keep files, somewhere to remember users and orders, and a way to survive busy days.”

The solution map:

1. App Service — the managed place where the web app runs.
2. Blob Storage — a container for photos, uploads, and other files.
3. Azure SQL — the organized memory for users and orders.
4. Azure Monitor autoscale — add or remove capacity when demand changes.

Keep the language simple and use Azure portal / Microsoft Learn wording only as short evidence snippets. The browser mock should show one address bar, one sentence, one highlight, and one analogy card—not a complete page.
