# AWS Deployment for Beginners: After the Build

Target: one 80–110 second Reel explaining a simple static frontend deployment.

1. Run the production build and find the `dist` or `build` output.
2. Create an S3 bucket and upload the built files.
3. Put CloudFront in front for delivery, caching, and HTTPS.
4. Use the CloudFront address first; connect a custom domain later if needed.
5. Open the live site, test a real path, and add a backend separately when the product needs one.
